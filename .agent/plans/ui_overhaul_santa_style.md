# 📋 Santa Styled AI UI/UX 전면 개편 마스터 플랜

본 문서는 프로젝트의 핵심 기능을 **산타토익(Santa)** 스타일의 프리미엄 UI/UX 구조로 재편하고, PC와 모바일 환경을 동시에 고려한 지능형 내비게이션 아키텍처를 수립하기 위한 마스터 플랜입니다.

---

## 🏛️ 하이브리드 내비게이션 아키텍처 (Core Architecture)

기기별 최적화된 사용자 경험을 제공하면서도, 논리적인 학습 흐름은 하나로 통합합니다.

### 1. 반응형 내비게이션 형태 (Responsive Forms)
*   **📱 모바일 (Mobile)**: 
    *   **Bottom Navigation Bar** 기반의 4대 메인 탭 구조.
    *   엄지손가락 동선 내에서 [홈, 선택 학습, AI 분석, 복습]을 즉시 전환.
*   **💻 PC (Desktop)**: 
    *   **Sidebar Navigation** 중심의 계층적 구조.
    *   사이드바 상단에 4대 메인 메뉴 고정.
    *   대메뉴 클릭 시 하위 카테고리(예: 시나공 보카, 파트별 문제)가 리스트 형태로 활성화되는 **위계형 내비게이션** 적용.

### 2. 동적 경로 추적 정책 (Dynamic Origin-Tracking Policy)
모든 세부 학습 페이지(보카, 문제 풀이 등)의 진입과 퇴출은 다음 시스템을 따릅니다.
*   **진입 시**: URL 파라미터 `?from=`을 통해 진입 출처를 반드시 전달.
    *   `from=home`: 대시보드 숙제/추천을 통해 진입
    *   `from=selection`: 직접 학습 목록을 선택해 진입
    *   `from=analysis`: 취약점 보완 미션을 통해 진입
*   **퇴출(종료/뒤로가기) 시**: `from` 파라미터 값에 따라 사용자가 이전에 머물던 탭/메뉴로 정확히 복구하도록 동적 리다이렉트 수행.

---

## 🗺️ 4대 핵심 메뉴 매핑 (The 4 Pillars)

| 탭 (Tab) | 경로 (Route) | 포함 기능 및 콘텐츠 |
| :--- | :--- | :--- |
| **나의 학습방 (Home)** | `/home` | 목표 점수 게이지, AI 예측 점수, 선생님 과제(Today's Mission) |
| **선택 학습 (Selection)** | `/selection` | 시나공 보카, 파트별 문제집, 인강/강의 리스트, 실전 모의고사 |
| **AI 분석 (Analysis)** | `/analysis` | 파트별 정답률 그래프, 취약 개념 분석, AI 처방전(맞춤형 미션) |
| **복습 (Review)** | `/review` | 오답 기록실, 최근 틀린 문제 재도전, 북마크 문제, 학습 타임라인 |

## 📅 단계별 실행 로직 (Implementation Roadmap)

### [Phase 1] 내비게이션 중추 구축 (Navigation Backbone)
- [x] **1.1 기기별 레이아웃 엔진**: `/selection`, `/analysis` 등 신규 루트 주소 체계 수립 및 PC/모바일 레이아웃 분기 로직 구현. (완료)
- [x] **1.2 PC 사이드바 고도화**: 대메뉴 - 하위 메뉴로 이어지는 계층적 사이드바 UI 컴포넌트 개발 및 동적 활성화 로직 적용. (완료)

### [Phase 2] '선택 학습 (Selection)' 통합 및 연동
- [x] **2.1 콘텐츠 허브 구축**: 흩어져 있던 보카, 파트별 선택 입구를 `/selection` 페이지에 카드 형태로 통합. (완료)
- [x] **2.2 PC 전용 3단계 계층 내비게이션**: 선택 학습 하위 메뉴에 [Part 1~7, 보카 Day, 실전 모의고사] 등 세부 항목을 아코디언 방식으로 추가. (완료)
- [ ] **2.3 동적 Exit 게이트 적용**: 시나공 보카를 포함한 모든 상세 페이지의 '종료' 버튼에 `Origin-Tracking` 로직 이식.

### [Phase 3] 'AI 분석 (Analysis)' - 데이터 시각화
- [ ] **3.1 통합 스킬 차트**: Part 1~7 숙련도를 직관적으로 보여주는 방사형 차트 인터페이스.
- [ ] **3.2 AI 처방 시스템**: 취약점 분석 결과를 실제 학습(`from=analysis`)으로 연결하는 미션 카드 생성.

### [Phase 4] '복습 (Review)' 및 기록 관리
- [ ] **4.1 오답 재도전 흐름**: 틀린 문제 데이터를 기반으로 한 즉시 복습 프로세스 구축.
- [ ] **4.2 통합 기록실**: 모든 테스트 결과(`Manager_Results`)를 타임라인으로 시각화.

## 🎨 디자인 정체성 (Visual Identity)
1.  **Glassmorphism**: 내비게이션 바와 카드 등에 반투명 효과와 미세 그라데이션 적용.
2.  **Focus Mode**: 세부 학습 진입 시 메뉴바를 숨기거나 최소화하여 몰입도 극대화.
3.  **Accent Strategy**: Indigo와 Cyan 컬러를 사용하여 AI 지능형 서비스의 느낌 강조.
