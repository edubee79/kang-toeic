# 02. 분류 기준 기호 정의 (Symbol Codebook)

본 문서는 깡쌤토익 시스템에서 사용하는 **159종의 모든 표준 기호(ID)**를 정의한 마스터 코드북입니다. 지문 및 문항 분류 시 반드시 아래에 정의된 ID만 사용해야 합니다.

---

## 🎧 [LC] 리스닝 파트 기호 (60 Items)

### 1. Part 1: Photograph Type (5)

> **[2026-02-20 개정]** 사진 기반 분류의 모호함 및 낮은 오답률로 인해 이론적 2단계 코드(P1_HUMA/P1_OBJE) 대신, 실제 데이터 파일에서 일관되게 사용 중인 5종 직관 코드로 교체함.

| ID | 명칭 | 상세 설명 |
| :--- | :--- | :--- |
| **Man** | 남성 1인 중심 | 남성 한 명의 동작·상태가 핵심인 사진 |
| **Woman** | 여성 1인 중심 | 여성 한 명의 동작·상태가 핵심인 사진 |
| **People** | 복수 인물 중심 | 두 명 이상의 인물이 등장하는 사진 |
| **Scene** | 야외 풍경/사물 중심 | 인물 없이 야외 풍경·사물 배치가 핵심인 사진 |
| **Room** | 실내 공간/사물 중심 | 인물 없이 실내 공간·가구 배치가 핵심인 사진 |

## 📖 [RC] 리딩 파트 기호 (99 Items)

### 1. Part 5: Hyper-Detailed Classification (80 - 핵심 문법/어휘)

#### 1.1 명사, 대명사, 형용사, 부사 (30)
*   **명사(N)**: `n1`(자리/형태), `n2`(가산/수일치), `n3`(복합명사), `n4`(사람vs사물), `n5`(특수형태)
*   **대명사(P)**: `p1`(인칭격), `p2`(부정대명사), `p3`(지시대명사), `p4`(재귀대명사), `p5`(on one's own), `p6`(소유격 강조)
*   **형용사(A)**: `a1`(수식), `a2`(보어), `a3`(분사형), `a4`(수량일치), `a5`(형용사숙어), `a6`(후치수식)
*   **부사(AV)**: `av1`(위치판단), `av2`(형/부수식), `av3`(빈도/접속부사)

#### 1.2 동사 및 준동사 (24)
*   **동사(V)**: `v1`(수일치), `v2`(능/수동태), `v3`(수동태세부), `v4`(시제일치), `v5`(당위법), `v6`(조동사), `v7`(자/타동사), `v8`(5형식)
*   **부정사(I)**: `i1`(명사적), `i2`(형용사적), `i3`(부사적), `i4`(i vs g 구분), `i5`(의문사+to), `i6`(의미상주어)
*   **동명사(G)**: `g1`(전치사목적어), `g2`(g vs n 구분), `g3`(관용명사), `g4`(의미차이), `g5`(숙어)
*   **분사(PA)**: `pa1`(전치수식), `pa2`(후치수식), `pa3`(보어자리), `pa4`(분사구문), `pa5`(관용분사)

#### 1.3 절, 연결어 및 특수구문 (22)
*   **명사절(NC)**: `nc1`(That/What), `nc2`(Whether/If), `nc3`(의문사절), `nc4`(복합관계사), `nc5`(의문사+To v)
*   **관계절(AC)**: `ac1`(격선택), `ac2`(That vs Which), `ac3`(부분표시), `ac4`(전치사+관계사), `ac5`(생략구조), `ac6`(관계부사)
*   **접속사(C)**: `c1`(등위/병렬), `c2`(상관접속사), `c3`(부사절), `c4`(접 vs 전), `c5`(축약구문)
*   **전치사(PR)**: `pr1`(기본의미), `pr2`(전 vs 부), `pr3`(전+동명사), `pr4`(동사+전 숙어), `pr5`(복합전치사)
*   **비교/도치(COM/S/INV)**: `com1~4`(비교급/최상급), `s1~2`(가정법), `inv1~5`(도치구문)

#### 1.4 정밀 어휘 (4)
*   `voc1`(순수의미), `voc2`(연어), `voc3`(뉘앙스구분), `voc4`(고정관용구)
