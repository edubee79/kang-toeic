# 04. 지문 표현 및 레이아웃 가이드 (Layout Rendering Guide)

본 문서는 데이터가 화면에 어떻게 그려지는지, 그리고 `type` 필드와 지문 텍스트(`content`)의 상관관계를 규정합니다.

## 🖼️ 1. `docType` 필드와 UI 레이아웃 매핑

> **파트별 대소문자 규칙**
> - **Part 6**: `docType`은 **소문자** 사용 (예: `"email"`, `"notice"`, `"article"`)
> - **Part 7**: `docType`은 **대문자** 사용 (예: `"EMAIL"`, `"NOTICE"`, `"ARTICLE"`). TypeScript Union Type으로 강제됨.
> - 두 파트 모두 각자의 규칙을 **전체 파일에서 일관되게** 사용 중이므로 혼용 금지.

### Part 6 허용 값 (소문자)
| docType | 대상 지문 유형 | 필수 조건 및 렌더링 특징 |
| :--- | :--- | :--- |
| **`email`** | 이메일, 편지 | 발신/수신/제목/날짜 헤더 포함 필수. |
| **`notice`** | 게시글, 공지 | 중앙 정렬 제목 및 박스 스타일. |
| **`article`** | 기사, 보고서 | 다단 레이아웃(PC 2단) 적용. |

### Part 7 허용 값 (대문자)
| docType | 대상 지문 유형 | 필수 조건 및 렌더링 특징 |
| :--- | :--- | :--- |
| **`EMAIL`** | 이메일, 편지 | 발신/수신/제목/날짜 헤더 포함 필수. |
| **`CHAT_MESSAGE`** | 채팅, 메신저 | `이름 [시간]` 형식 준수 시 말풍선 레이아웃. |
| **`ARTICLE`** | 기사, 보고서 | 다단 레이아웃(PC 2단) 및 중앙 구분선 적용. |
| **`NOTICE`** / **`ANNOUNCEMENT`** | 게시글, 공지 | 중앙 정렬 제목 및 박스 스타일. |
| **`SCHEDULE`** | 일정표, 영업시간 | 본문 자체가 마크다운 Table로 구성됨. |
| **`INSTRUCTIONS`** | 사용설명서, 지침 | 번호 목록 또는 단계별 서술 구조. |
| **`LETTER`** / **`INVITATION`** | 서신, 초대장 | EMAIL과 유사한 헤더 구조. |
| **`ADVERTISEMENT`** / **`BROCHURE`** | 광고, 홍보 | 중앙 정렬 및 강조 레이아웃. |
| **`TEXT_MESSAGE`** / **`CHAT_MESSAGE`** | 문자, 메신저 | 말풍선 렌더링. |
| **`FORM`** / **`RECEIPT`** | 양식, 영수증 | 표(Table) 형식 렌더링. |
| **`REVIEW`** / **`INFORMATION`** / **`WEBPAGE`** / **`WEB_PAGE`** | 리뷰, 웹페이지 | 일반 텍스트 블록. |

## ✍️ 2. 마크다운(Markdown) 작성 표준

지문(`content`) 내 가독성 향상을 위해 다음 문법을 준수한다.

*   **표 (Table)**: 
    *   헤더 구분선 `---|---` 필수. 
    *   일정표, 영업시간, 가격표는 반드시 표 형식 사용.
*   **특수 강조**:
    *   중요 고유명사나 제목은 `**Bold**` 처리.
    *   참조 규정이나 필기체는 `*Italic*` 처리.
*   **줄바꿈**: 
    *   이메일 본문과 헤더 사이는 `\n\n` (빈 줄 한 개) 필수.

## 📍 3. 특수 마커 작성법

*   **문장 삽입용 마커**: `[1]`, `[2]`, `[3]`, `[4]` 순서로 지문 내에 정확히 배치 (공백 포함 여부 원본 대조).
*   **Part 6 빈칸 마커**: `___131___` 형식 사용. (숫자는 문항 번호)
