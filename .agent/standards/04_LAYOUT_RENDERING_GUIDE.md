# 04. 지문 표현 및 레이아웃 가이드 (Layout Rendering Guide)

본 문서는 데이터가 화면에 어떻게 그려지는지, 그리고 `type` 필드와 지문 텍스트(`content`)의 상관관계를 규정합니다.

## 🖼️ 1. `type` 필드와 UI 레이아웃 매핑

| docType (대문자) | 대상 지문 유형 | 필수 조건 및 렌더링 특징 |
| :--- | :--- | :--- |
| **`EMAIL`** | 이메일, 편지 | 발신/수신/제목/날자 헤더 포함 필수. 본문 상단 여백 부여. |
| **`CHAT_MESSAGE`** | 채팅, 메신저 | `이름 [시간]` 형식 준수 시 말풍선 레이아웃으로 변환. |
| **`ARTICLE`** | 기사, 보고서 | 다단 레이아웃(PC 2단) 및 중앙 구분선 적용. |
| **`NOTICE`** | 게시글, 공지 | 중앙 정렬 제목 및 박스 스타일 적용 가능. |
| **`SCHEDULE`** | 일정표, 영업시간 | 본문 자체가 마크다운 Table로 구성됨. |

## ✍️ 2. 마크다운(Markdown) 작성 표준

지문(`content`) 내 가독성 향상을 위해 다음 문법을 준수한다.

*   **표 (Table)**: 
    *   헤더 구분선 `---|---` 필수. 
    *   일정표, 영업시간, 가격표는 반드시 표 형식 사용.
*   **특수 강조**:
    *   중요 고유명사나 제목은 `**Bold**` 처리.
    *   참조 규정이나 필기체는 `*Italic*` 처리.
*   **줄바꿈**: 
    *   이메일 본문과 헤더 사이는 `\n\n` (빈 줄 한 개) 필수.

## 📍 3. 특수 마커 작성법

*   **문장 삽입용 마커**: `[1]`, `[2]`, `[3]`, `[4]` 순서로 지문 내에 정확히 배치 (공백 포함 여부 원본 대조).
*   **Part 6 빈칸 마커**: `___131___` 형식 사용. (숫자는 문항 번호)
