# 🗺️ 깡쌤토익 데이터 표준 시스템 (Standard Index)

본 폴더는 깡쌤토익 프로젝트의 데이터 정합성과 분석 정확도를 100% 유지하기 위한 **종합 지침서**입니다. 에이전트는 데이터 생성, 수정, 분류 시 아래 문서의 위계에 따라 행동해야 합니다.

## 🏛️ 문서 위계 및 참조 관계

1.  **[01_DATA_STRUCTURE_STANDARD.md](./01_DATA_STRUCTURE_STANDARD.md)** (데이터 구조 및 용어 표준)
    *   **내용**: 파트별 데이터 파일에 사용되는 **모든 함수(Interface) 및 필드명을 표준화**하고, 각 필드에 **어떤 성격의 정보**를 넣어야 하는지 규정함.
    *   **에이전트 의무**: 데이터 생성 및 수정 시, 이 문서에 정의된 **용어 정석**과 **정보 배치 규칙**(예: `docType`과 `type`의 구분)을 100% 일관되게 준수해야 함.

2.  **[02_SYMBOL_CODEBOOK.md](./02_SYMBOL_CODEBOOK.md)** (기호 정의)
    *   **내용**: "담는 내용물". 표준 기호(ID) 목록 및 의미.
    *   **참조 시점**: `docType`, `classification` 등에 어떤 코드를 넣을지 결정할 때.

3.  **[03_LC_CRITERIA.md](./03_LC_CRITERIA.md)** (LC 판정 논리 - Part 1~4)
     *   **내용**: "판단의 근거". LC 각 파트의 기호를 선택하는 로직(Trigger/Rule).
     *   **참조 시점**: Part 1~4 문항 유형 분류 시. 특히 Part 2의 `Indirect` 최우선 판정 원칙 참조.

3b. **[03_RC_CRITERIA.md](./03_RC_CRITERIA.md)** (RC 판정 논리 - Part 5~7)
     *   **내용**: "판단의 근거". RC 각 파트의 기호를 선택하는 로직.
     *   **참조 시점**: Part 5~7 문항 유형 분류 시.

4.  **[04_LAYOUT_RENDERING_GUIDE.md](./04_LAYOUT_RENDERING_GUIDE.md)** (시각 표현)
    *   **내용**: "보여주는 방식". UI 레이아웃 및 렌더링 규칙.
    *   **참조 시점**: `type` 필드를 결정하거나 지문에 마크다운 표(Table) 등을 작성할 때.

5.  **[05_EXTRACTION_WORKFLOW.md](./05_EXTRACTION_WORKFLOW.md)** (작업 절차)
    *   **내용**: "실전 매뉴얼". 데이터 추출부터 최종 검증까지의 단계.
    *   **참조 시점**: 이미지에서 텍스트를 추출하고 시스템에 이식하는 실제 작업을 수행할 때.

---
**⚠️ 주의**: 모든 문서는 상호 연결되어 있습니다. 예를 들어 3번 문서(논리)에서 판단된 결과는 반드시 2번 문서(기호)에 정의된 ID여야 하며, 1번 문서(구조)의 약속된 필드에 담겨야 합니다.
